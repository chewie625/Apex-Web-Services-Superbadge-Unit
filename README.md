This superbadge basically is to write code so that allow external applications to calls into Salesforce to retrieve information (get method).

To call Salesforce, use https://My Domain Name.my.salesforce.com/services/apexrest/xxx/

My Domain Name = Go to Setup -> My Domain to look for the domain Name.

xxx = the Sobject Name (e.g. Accounts, Contacts...)

For Salesforce Superbadge - https://trailhead.salesforce.com/content/learn/superbadges/superbadge-custom-api-sbu
